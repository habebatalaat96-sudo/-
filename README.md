# Nouryyy Surprise ❤️🌍

A small romantic React surprise made for Nouryyy.

## Run it

1. Open this folder in VS Code.
2. Open the terminal inside the folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

The project is mobile-friendly and uses React, Vite, Framer Motion, and Lucide React.
